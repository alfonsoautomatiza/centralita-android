# Manual de uso

Esta guía cubre el uso diario de Centralita CRM: activar el terminal, recibir llamadas identificadas y gestionar las llamadas pendientes.

## Inicio rápido

1. Instala la app y ábrela.
2. Concede los permisos que solicita (teléfono, registro de llamadas y notificaciones).
3. Envía la solicitud de alta al administrador o introduce tu código de activación.
4. Cuando el administrador apruebe el terminal, pulsa **Sincronizar**.
5. Comprueba que **Detección de llamadas activa** está encendida en **Configuración**.

A partir de ese momento, cada llamada de un contacto del CRM muestra su ficha automáticamente.

## 1. Alta del terminal

Por seguridad, ningún teléfono recibe datos sin aprobación expresa.

| Paso | Qué haces | Qué ocurre |
| --- | --- | --- |
| Solicitud | Pulsa **Enviar solicitud al administrador** | El terminal genera sus propias claves y envía la solicitud |
| Aprobación | El administrador aprueba el terminal | El terminal queda autorizado para tu empresa |
| Activación | Opcionalmente, introduce el **código de activación** y pulsa **Validar** | El terminal queda vinculado |
| Primera sincronización | Pulsa **Sincronizar** | Se descargan y verifican los datos de tus contactos |

Si cambias de teléfono o reinstalas la app, deberás solicitar el alta de nuevo.

## 2. Llamadas entrantes

Cuando suena el teléfono:

- **Contacto encontrado:** la notificación muestra el nombre, la empresa y el estado del cliente.
- **Número desconocido:** la notificación indica que el número no está en el CRM.

Cada llamada genera una **tarjeta** en la pantalla principal.

## 3. Tarjetas de llamadas

| Acción | Uso |
| --- | --- |
| **Llamar** | Devuelve la llamada |
| **WhatsApp** | Abre una conversación con ese número |
| **Nota** | Escribe una nota y pulsa **Guardar** para registrarla en el CRM |
| **Eliminar** | Quita la tarjeta |
| **Limpiar tarjetas** | Vacía todas las tarjetas tras confirmar |

En **Configuración → Persistencia de tarjetas** eliges durante cuánto tiempo se conservan.

## 4. Búsqueda

Escribe en el buscador un teléfono, un nombre o una empresa. Si no tienes conexión, la búsqueda usa la caché local del teléfono.

## 5. Funcionamiento sin conexión

Los contactos se guardan cifrados en el teléfono, por lo que la identificación funciona sin cobertura.

Por seguridad, la caché caduca si pasa demasiado tiempo sin sincronizar. En ese caso verás **"Necesario refrescar conexión"**: conéctate y pulsa **Sincronizar**.

## 6. Configuración

| Opción | Efecto |
| --- | --- |
| **Detección de llamadas activa** | Activa o desactiva la identificación automática |
| **Refresco automático** | Frecuencia de sincronización (5 min a 6 horas) |
| **Números ignorados** | Números que nunca generan tarjeta ni notificación |
| **Notificaciones** | Comprueba el permiso de notificaciones |
| **Estado del teléfono** | Comprueba los permisos de llamadas |

## 7. Solución de problemas

| Síntoma | Solución |
| --- | --- |
| No aparece la ficha al recibir una llamada | Comprueba **Detección de llamadas activa** y los permisos de teléfono y notificaciones |
| "Necesario refrescar conexión" | Conéctate a internet y pulsa **Sincronizar** |
| "Terminal no autorizado" | El administrador debe aprobar o volver a aprobar el terminal |
| Deja de detectar llamadas tras un tiempo | Excluye la app de la optimización de batería del sistema |

Si el problema persiste, abre una incidencia **sin incluir datos de clientes**.
